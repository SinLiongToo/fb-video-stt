FB 影片轉文字

貼上 Facebook 影片或 Reel 網址，在你自己的電腦上辨識語音，輸出逐字稿。

版本 v1.6｜最後更新 2026-10-04 18:06（台灣時間）｜完整記錄見「❓ 說明」

使用說明

開始之前

這個頁面要透過本機伺服器開：雙擊資料夾裡的 start.bat（或執行 python server.py）， 再用瀏覽器開 http://localhost:8792/。直接雙擊 index.html 沒辦法抓 FB 影片。 關掉那個黑色視窗，伺服器就停了。

線上版（GitHub Pages）

也可以從 https://sinliongtoo.github.io/fb-video-stt/ 開。線上版只是畫面， 下載影片和辨識還是在你自己的電腦上跑，所以一樣要先開 start.bat；沒開的話頁面上會出現紅色提醒。 第一次用時瀏覽器可能會問「允許存取本機網路裝置」，請按允許。建議用 Chrome 或 Edge； Safari 會擋住網頁連到本機，請改開 http://localhost:8792/。

第一次在新電腦上用：到 GitHub 下載這個專案，裝好 Python 後執行 pip install -r requirements.txt，之後雙擊 start.bat 即可。

基本步驟

  1. 在 Facebook 影片或 Reel 上按「分享 → 複製連結」，貼到網址欄。
  2. 選語言（不確定就用「自動偵測」），再選「輸出」：只要原文、只要英文翻譯，或原文＋英文並列。
  3. 按「開始轉文字」或按 Enter。進度條依序是：下載音軌 → 載入模型 → 辨識中。
  4. 辨識出來的文字會邊跑邊出現，跑完會顯示影片長度、語言、模型、耗時。

語言怎麼選

  • 自動偵測：大部分情況用這個。英文、日文、法語、華語等都會照原本的語言寫出來 （支援約 99 種語言，選單沒列的語言也可以）。影片很短、或開頭都是音樂時偶爾會判錯，這時再手動指定語言。
  • English／日本語／Français：確定是這個語言時可以直接指定，避免自動偵測判錯。
  • 中文（繁體）：確定是華語才選。英文影片不要選中文，會被硬翻成錯誤很多的中文。
  • 台語 → 華語（實驗性）：台語影片用。聽得懂台語，但寫出來的是華語 （例如「五千箍是毋是會當予我分做幾擺仔予你」會變成「五千塊能否分成幾次給你」），不是台語漢字逐字稿。 選這個時模型選單不適用。

輸出：原文、英文、或並列

  • 只要原文：照影片講的語言寫出來（預設）。
  • 只要英文翻譯：直接得到英文，例如中文或法語影片會得到英文字幕。
  • 原文＋英文並列：每句原文下面接一行英文（灰色斜體），一句對一句。 做法是先辨識原文，再把每一句對應的聲音拿去翻譯，所以比較慢，大約是只要原文的 3 倍時間 （1 分鐘影片約 4 分鐘）；進度條前半是辨識、後半是翻譯。 如果影片本來就是英文，就不會再翻一次。

只能翻成英文，沒辦法翻成中文（辨識模型本身的限制）。 要翻譯請用 small、medium 或 large-v3；large-v3-turbo 沒學過翻譯，常常還是輸出原文。 台語模式不能翻譯。

模型怎麼選

越大越準、也越慢。這台電腦沒有顯示卡（GPU），建議 small。 第一次用某個模型會先下載（幾百 MB 到 3GB），之後就不用。 參考：1 分鐘英文影片，small 約 20 秒；台語模式約 2 分半。

結果怎麼用

  • 顯示時間碼：勾選時每段前面有 [分:秒]，複製／下載 .txt／.md／Word 也會跟著帶時間碼。
  • 複製：複製到剪貼簿。
  • 下載 .txt：純文字檔。
  • 下載 .srt：字幕檔，可以匯入剪映、Premiere、YouTube 等。並列模式會是雙語字幕（原文在上、英文在下）。
  • 下載 .md：Markdown 筆記檔，含標題、網址、資訊列，可以直接放進 Obsidian、Notion 等筆記軟體。
  • 下載 Word：.docx，含影片標題、網址、資訊列。
  • 並列模式下，以上每一種都是「原文一行、英文一行」。

常見問題

  • 「失敗」或抓不到影片：只能抓公開影片；私人社團、限朋友的影片抓不到。 也可能是 Facebook 改版，更新 yt-dlp 試試：pip install -U yt-dlp。
  • 「連線中斷」或「連不到你電腦上的伺服器」：伺服器的黑色視窗沒開或被關掉了，重新執行 start.bat。
  • 新功能沒出現：伺服器要重開才會用到新版程式。在黑色視窗按 Ctrl+C，再執行一次 start.bat。
  • 「找不到台語模型」：台語模型要另外下載一次，指令在 README「台語模型」。
  • 辨識結果有錯字：語音辨識一定會有錯，請當草稿自己校對；換大一點的模型通常會好一些。
  • 音檔會被上傳嗎？不會。下載和辨識都在你自己的電腦上，暫存音檔辨識完就刪掉。
